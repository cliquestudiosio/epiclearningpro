# Epic Learning Pro — Colors & Fonts Used in This Build

Audit of every color and typeface actually referenced in the live site (`artifacts/epic-learning-pro/`), for matching against Olivia's official branding package. Generated by grepping `src/index.css` (design tokens) and `src/pages/Home.tsx` (page content/inline styles) — the admin portal's own UI chrome (`public/admin-portal.css`) is excluded since that's editor tooling, not site branding.

Note: Olivia can change brand colors live via the admin portal's color-swatch tool, which rewrites these hexes wherever they appear on the page. The values below are the **current build defaults** as shipped in source.

## UI design tokens (`src/index.css` — light mode, HSL → hex)

These drive buttons, borders, cards, form inputs, etc. via Tailwind/shadcn tokens. They're close to (but not always pixel-identical to) the brand hexes above, since they're independently defined in HSL:

| Token | HSL | Hex equivalent | Notes |
|---|---|---|---|
| `--background` | `0 0% 100%` | `#FFFFFF` | Page background |
| `--foreground` | `222 47% 11%` | `#0F1729` | Body text (dark navy) |
| `--border` / `--input` | `214 32% 91%` | `#E1E7EF` | Borders, input outlines |
| `--primary` / `--ring` | `260 74% 64%` | `#8D5FE7` | ≈ matches `--brand-primary` `#8B5FE6` |

## Shadows

All shadows use plain black at low opacity, no color to match:
`rgba(0,0,0,0.02)` through `rgba(0,0,0,0.08)` (see `--shadow-*` tokens in `index.css`).

## Fonts

Loaded via Google Fonts in `src/index.css` (line 1):

| Role | Font | Weights | CSS variable |
|---|---|---|---|
| Body / sans-serif (`font-sans`) | **Outfit** | 300, 400, 500, 600, 700 | `--app-font-sans` |
| Headings `h1`–`h6` / serif (`font-serif`) | **Playfair Display** | 400, 600 (regular), 400 (italic) | `--app-font-serif` |
| Monospace (fallback only, not used in visible content) | System mono stack (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New"`) | — | `--app-font-mono` |

The hero tagline specifically uses `font-serif italic` (Playfair Display italic) in gold (`#F0C84A`).

## Where to look if colors change

- Brand swatches (what Olivia edits live): `--brand-primary`, `--brand-secondary`, `--brand-accent`, `--brand-hero-start`, `--brand-hero-end`, `--brand-tint` in `artifacts/epic-learning-pro/src/index.css`.
- Section-specific gradients/overlays: inline `style={{ background: ... }}` in `artifacts/epic-learning-pro/src/pages/Home.tsx`.
- UI component tokens (buttons, cards, inputs): `:root` / `.dark` blocks in the same `index.css`.
